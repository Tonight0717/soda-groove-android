# 소다그루브 · Soda Groove

갤럭시에 APK로 설치하는 개인용 LP 턴테이블입니다. Android 7.0 이상을 대상으로 합니다. Java로 그린 네이티브 턴테이블과 홈 위젯을 사용하며 영상 영역에는 YouTube 공식 플레이어를 표시합니다.

## 설치와 첫 재생

1. 갤럭시로 **SodaGroove.apk**를 받습니다. [최신 버전 다운로드](https://github.com/Tonight0717/soda-groove-android/releases/latest)
2. **내 파일 → 다운로드**에서 APK를 누르고 **설치**를 선택합니다. 설치 출처를 묻는 경우 이 파일을 연 앱에 대한 허용 여부를 확인하세요. 메뉴 이름은 One UI 버전에 따라 달라집니다.
3. YouTube 또는 YouTube Music에서 곡이나 공개 재생목록의 **공유 → 링크 복사**를 누릅니다.
4. 소다그루브의 **링크 열기**에 붙여넣고, 아래쪽 공식 플레이어의 **▶**를 누릅니다. 영상이 재생되면 LP가 돌고 가운데에 현재 곡의 썸네일이 보입니다.
5. 하늘·민트·코랄은 **색상**에서 고릅니다. 진행바를 끌거나 바늘의 연두색 끝을 잡고 판 안쪽으로 옮긴 뒤 놓으면 원하는 위치로 이동합니다. 바깥쪽은 곡의 시작, 안쪽은 끝입니다.
6. **진열장에 저장**을 누릅니다. 재생목록을 듣는 중에는 현재 곡과 목록 중 하나를 고를 수 있습니다. **진열장**에서 커버를 누르면 다시 열리고, 삭제는 확인 후 적용됩니다. 목록의 표지는 저장할 때의 곡 커버를 사용합니다.
7. 갤럭시 홈 화면 빈 곳을 길게 누르고 **위젯 → 소다그루브 턴테이블**을 추가하세요. 최근 재생한 곡을 표시하고 누르면 해당 곡의 턴테이블이 열립니다.

화면을 잠그거나 홈으로 나가면 재생을 멈춥니다. 위젯은 정지된 턴테이블입니다. 다시 들을 때 앱 안에서 ▶를 누르세요. YouTube에서 사용하는 네트워크 데이터와 서비스 자체의 광고는 그대로 적용됩니다. 외부 재생 제한, 비공개 영상, 지역 제한, 로그인 요구 등은 원래 서비스의 **열기** 버튼으로 확인하세요. 저장하는 정보는 링크·표시 제목·커버 식별자·색상입니다. 음악 파일을 내려받지 않습니다. 앱 데이터 삭제나 앱 제거 시 진열장도 지워집니다.

## PC 없이 다음 APK 받기

[자동 빌드 목록](https://github.com/Tonight0717/soda-groove-android/actions/workflows/android.yml)에서 초록색으로 성공한 실행을 열고 아래 **Artifacts → SodaGroove-APK**를 눌러 ZIP을 받으세요. GitHub 로그인이 필요할 수 있습니다. 압축을 풀면 설치할 APK가 나옵니다. 보관 기간은 7일입니다. 새 빌드는 이 페이지의 **Run workflow → main → Run workflow**로 실행할 수 있습니다. main에 수정 사항을 저장해도 테스트와 빌드가 실행됩니다.

이 프로젝트는 공개 저장소의 표준 Ubuntu 러너를 사용합니다. 결제 API 키나 운영 서버가 필요하지 않습니다. APK 업데이트에 필요한 서명 정보는 저장소의 Actions secrets인 SODA_KEY와 SODA_PASSWORD에 등록합니다. 기존 저장소에서는 이미 등록된 값을 사용합니다. 프로젝트를 개인 계정으로 복사하면 이 값들은 함께 복사되지 않습니다. [GitHub Actions 사용 조건](https://docs.github.com/en/actions/concepts/billing-and-usage)

## 갤럭시에서 확인할 항목

| 확인 순서 | 기대 결과 |
|---|---|
| 유튜브 곡과 유튜브 뮤직 곡을 각각 열고 재생·일시정지 | 영상·소리·LP 회전·바늘 상태가 함께 바뀝니다. |
| 공개 재생목록에서 첫 곡 끝부분으로 이동 | 다음 곡으로 넘어갈 때 커버·제목·진행 시간이 바뀝니다. |
| 진행바와 바늘을 각각 곡 중간으로 이동 | 소리가 해당 구간부터 들리고 공식 플레이어의 시간도 변합니다. |
| 곡과 목록을 각각 저장하고 색상을 바꾼 뒤 앱 재실행 | 진열장 두 항목과 선택한 색상이 유지됩니다. |
| 홈 이동과 화면 잠금, 위젯 누르기 | 재생이 멈추고 위젯은 마지막으로 재생한 곡을 엽니다. |
| 잘못된 주소, 임베드가 제한된 곡 열기 | 잘못된 링크는 입력창에서 안내합니다. 재생 제한은 공식 플레이어 또는 상태 문구에서 확인하고 원본을 열 수 있습니다. |

## 이전 상태로 돌아가기

- **첫 설치를 취소하려면** 앱 아이콘을 길게 눌러 설치를 삭제하세요. 진열장과 색상도 삭제됩니다. 위젯만 빼려면 위젯을 길게 눌러 홈 화면에서 제거하세요.
- **나중에 업데이트한 뒤 첫 버전으로 돌아가려면** 진열장을 유지할 때는 같은 서명과 더 높은 버전 번호가 필요합니다. 저장소를 내려받은 폴더에서 아래 명령으로 첫 버전 소스를 복원하고 새 빌드를 실행하세요. 깨끗한 새 복제본에서 실행하면 기존 작업물을 보호할 수 있습니다. 빌드가 끝난 뒤 받은 APK를 기존 앱 위에 설치합니다.

```sh
git clone https://github.com/Tonight0717/soda-groove-android.git soda-restore
cd soda-restore
git restore --source v1.0 -- app
git commit -am "Restore first release app"
git push
```

- **진열장을 지워도 괜찮다면** 현재 앱을 삭제한 후 첫 버전 APK를 설치해도 됩니다. 이미 설치된 최신 앱 위에 낮은 버전 번호의 APK를 바로 설치하면 Android가 거부할 수 있습니다.

## 프로젝트 구성

`app/src/main/java`에 네이티브 화면·바늘 조작·링크 해석·저장·위젯 코드가 있고, `app/src/main/assets/player.html`에서 공식 IFrame API를 연결합니다. `app/src/test`에 링크와 화면·저장 흐름 검사가 있습니다. APK는 `.github/workflows/android.yml`로 빌드합니다. 공식 플레이어는 스크롤 영역 밖에 두어 LP와 겹치지 않게 했습니다. [YouTube 플레이어 표시 요건](https://developers.google.com/youtube/terms/required-minimum-functionality)
