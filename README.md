# 소다그루브 · Soda Groove

갤럭시에 APK로 설치하는 개인용 LP 턴테이블입니다. Android 7.0 이상을 대상으로 합니다. Java로 그린 네이티브 턴테이블과 홈 위젯을 사용하며, 유튜브·유튜브 뮤직 링크를 파스텔 카드 위의 레코드로 보여 줍니다. 앱 안에서는 소리를 재생하지 않고, 듣기는 **원본 열기**로 넘깁니다.

## 설치와 첫 사용

1. 갤럭시로 **SodaGroove.apk**를 받습니다. [최신 버전 다운로드](https://github.com/Tonight0717/soda-groove-android/releases/latest)
2. **내 파일 → 다운로드**에서 APK를 누르고 **설치**를 선택합니다. 설치 출처를 묻는 경우 이 파일을 연 앱에 대한 허용 여부를 확인하세요. 메뉴 이름은 One UI 버전에 따라 달라집니다.
3. YouTube 또는 YouTube Music에서 곡이나 공개 재생목록의 **공유 → 링크 복사**를 누릅니다.
4. 소다그루브의 **링크 열기**에 붙여넣으면 카드 위쪽에 서비스 이름(`YouTube` / `YouTube Music`)이, 가운데에 곡 커버가, 그 아래에 실제 곡 제목이 나타납니다. 제목과 커버는 유튜브에서 한 번 읽어 와 기기에 저장합니다.
5. **LP판을 탭**하면 판이 천천히 돌고 바늘이 판 위로 내려앉습니다. 한 번 더 탭하면 멈춥니다. 앱은 소리를 내지 않으므로, 듣기는 카드 아래 **원본 열기**(`뮤직에서 열기` / `유튜브에서 열기`)로 유튜브 뮤직 또는 유튜브 앱에서 이어 갑니다.
6. 하늘·민트·코랄은 **색상**에서 고릅니다. 카드 배경과 레코드의 색감이 함께 바뀝니다.
7. **진열장에 저장**을 누릅니다. 재생목록을 열어 둔 경우에는 현재 곡과 목록 중 하나를 고를 수 있습니다. **진열장**에서 카드를 누르면 다시 열리고, 삭제는 확인 후 적용됩니다.
8. 갤럭시 홈 화면 빈 곳을 길게 누르고 **위젯 → 소다그루브 턴테이블**을 추가하세요. 마지막으로 연 곡을 표시하고 누르면 그 곡의 턴테이블이 열립니다.

앱 안에서 재생하지 않으므로 화면을 잠그거나 홈으로 나가도 멈출 재생이 없고, 백그라운드 재생 알림도 만들지 않습니다. 인터넷은 곡 제목과 커버를 한 번 읽을 때만 쓰고, 연결이 없으면 제목 자리에 `YouTube · 곡ID`가 대신 표시됩니다. 저장하는 정보는 링크·표시 제목·커버 식별자·색상입니다. 음악 파일을 내려받지 않으며, 앱 데이터 삭제나 앱 제거 시 진열장도 지워집니다.

## PC 없이 다음 APK 받기

[자동 빌드 목록](https://github.com/Tonight0717/soda-groove-android/actions/workflows/android.yml)에서 초록색으로 성공한 실행을 열고 아래 **Artifacts → SodaGroove-APK**를 눌러 ZIP을 받으세요. GitHub 로그인이 필요할 수 있습니다. 압축을 풀면 설치할 APK가 나옵니다. 보관 기간은 7일입니다. 새 빌드는 이 페이지의 **Run workflow → main → Run workflow**로 실행할 수 있습니다. main에 수정 사항을 저장해도 테스트와 빌드가 실행됩니다.

이 프로젝트는 공개 저장소의 표준 Ubuntu 러너를 사용합니다. 결제 API 키나 운영 서버가 필요하지 않습니다. APK 업데이트에 필요한 서명 정보는 저장소의 Actions secrets인 SODA_KEY와 SODA_PASSWORD에 등록합니다. 기존 저장소에서는 이미 등록된 값을 사용합니다. 프로젝트를 개인 계정으로 복사하면 이 값들은 함께 복사되지 않습니다. [GitHub Actions 사용 조건](https://docs.github.com/en/actions/concepts/billing-and-usage)

## 갤럭시에서 확인할 항목

| 확인 순서 | 기대 결과 |
|---|---|
| 첫 실행 | 진한 영상 창 없이 파스텔 카드와 빈 턴테이블이 보이고, 아래에 `첫 레코드를 올려 보세요`가 있습니다. |
| 유튜브 곡과 유튜브 뮤직 곡을 각각 열기 | 카드 위 이름이 `YouTube` / `YouTube Music`으로 바뀌고 커버와 실제 제목이 나타납니다. |
| 공개 재생목록 링크 열기 | 목록 이름이 잡히면 그 이름이, 아니면 `재생목록 · 목록ID`가 제목 자리에 표시됩니다. |
| LP판 탭 | 판이 돌고 바늘이 판 위로 내려갑니다. 다시 탭하면 멈추고 바늘이 제자리로 돌아옵니다. |
| 원본 열기 | 유튜브 또는 유튜브 뮤직 앱(없으면 브라우저)에서 같은 링크가 열립니다. |
| 곡과 목록을 각각 저장하고 색상을 바꾼 뒤 앱 재실행 | 진열장 두 항목과 선택한 색상이 유지됩니다. |
| 홈 이동과 위젯 누르기 | 위젯이 마지막으로 연 곡을 보여 주고, 누르면 그 곡의 턴테이블이 열립니다. |
| 인터넷을 끈 채 링크 열기 | 제목 자리에 `YouTube · 곡ID`가 나오고 나머지 조작은 그대로 됩니다. |

## 이전 상태로 돌아가기

- **첫 설치를 취소하려면** 앱 아이콘을 길게 눌러 설치를 삭제하세요. 진열장과 색상도 삭제됩니다. 위젯만 빼려면 위젯을 길게 눌러 홈 화면에서 제거하세요.
- **나중에 업데이트한 뒤 첫 버전으로 돌아가려면** 진열장을 유지할 때는 같은 서명과 더 높은 버전 번호가 필요합니다. 저장소를 내려받은 폴더에서 아래 명령으로 첫 버전 소스를 복원하고 새 빌드를 실행하세요. 깨끗한 새 복제본에서 실행하면 기존 작업물을 보호할 수 있습니다. 빌드가 끝난 뒤 받은 APK를 기존 앱 위에 설치합니다.

```sh
git clone https://github.com/Tonight0717/soda-groove-android.git soda-restore
cd soda-restore
git restore --source v1.0 -- app
git commit -am "Restore first release app"
git push
```

- **진열장을 지워도 괜찮다면** 현재 앱을 삭제한 후 첫 버전 APK를 설치해도 됩니다. 이미 설치된 최신 앱 위에 낮은 버전 번호의 APK를 바로 설치하면 Android가 거부할 수 있습니다.

## 프로젝트 구성

`app/src/main/java`에 화면·턴테이블 그림·링크 해석·제목/커버 읽기·저장·위젯 코드가 있고, `app/src/test`에 링크 해석, 빈 화면, 회전 토글, 제목 캐시, 진열장 저장·삭제 검사가 있습니다. APK는 `.github/workflows/android.yml`로 테스트와 함께 빌드합니다. 앱에는 웹뷰나 영상 재생 구성 요소가 없습니다.
